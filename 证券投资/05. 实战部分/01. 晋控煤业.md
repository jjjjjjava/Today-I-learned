## 04. 复盘

如果是您，作为专业人士，您会如何处理呢？

### 4.1 我做错了什么

做对的地方：

- 选股逻辑清晰：上升通道+趋势线支撑
- 入场位置不错：回踩趋势线+年线支撑
- 有止损意识：知道跌破趋势线要走

做错的地方：

- 仓位管理失控
- 涨了一天，加仓到7成，没有等待任何确认信号

根本原因：混淆了"防守信号"和"进攻信号"

- 趋势线支撑 = 防守信号（告诉你下方有保护）
- 突破压力位 = 进攻信号（告诉你可以加仓）

### 4.2 如果再来，应该怎么做

第一阶段：观察与试探

- ```
  观察到：周线上升通道完好，日线回踩趋势线+年线
  判断：这是一个低风险试探机会
  操作：12.09回踩反弹当天，入场2-3成
  止损：设在趋势线下方13元，亏损约10%
  ```

第二阶段：等待确认

- ```
  等待信号：
  1. 站稳5日均线3天以上
  2. 或者突破14.79短期压力位
  3. 或者形成更高的波段低点
  
  在此之前：不加仓，只观察
  ```

第三阶段：确认后加仓

- ```
  如果突破14.79且放量：
  → 加仓到5成
  → 止损上移到14元
  
  如果继续上涨突破前高15.5：
  → 加仓到7成
  → 止损上移到14.79（突破位）
  ```

第四阶段：持仓与止盈

- ```
  目标位：
  - 第一目标：前高18.47附近，减仓1/3
  - 第二目标：周线通道上轨（约20元），再减1/3
  - 剩余1/3：跟随趋势，跌破周线趋势线离场
  ```

### 4.3 反思

我的策略框架没问题，问题出在执行层面。建议：

#### 1.制定加仓清单

每次交易前写下：

```
试探仓条件：_______ 仓位：___成
确认仓条件：_______ 仓位：___成  
突破仓条件：_______ 仓位：___成
```

#### 2.强制冷静期

加仓前必须等待至少2个交易日，避免情绪化决策。

#### 3.记录每笔交易

写下入场理由、加仓理由、止损位。事后复盘对照，这是进步最快的方式。

您的方向是对的，只是需要在纪律性上再打磨。这次晋控煤业的仓位虽然重了点，但入场位置不差，耐心等待市场给答案就好。
