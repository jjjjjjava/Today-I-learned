# Android Interview 学习追踪 v2 设计

## 背景

当前 `Android-Interview` 的动态执行系统存在职责重叠：

- `任务池` 同时承担候选任务、进行中状态、未完成回流和复习入口。
- `今日任务`、`本周计划`、`学习日志` 都在不同程度上保存状态。
- `复习队列`、`薄弱点`、`未完成队列` 已经迁移到学习卡片模型，但模板和旧任务池仍保留旧模型字段。

v2 的目标是收敛为一个清晰模型：

```text
学习卡片 = 唯一状态源
队列 = 卡片索引视图
任务池 = 未开始候选输入
今日任务 = 当天工作台
本周计划 = 方向和容量约束
学习日志 = 事实流水和决策记录
```

## 核心原则

1. 任务池只回答：有哪些想学但还没开始学习的任务。
2. 新任务一旦被选中并开始学习，必须先创建学习卡片，再进入今日任务。
3. 学习卡片是唯一状态源，保存状态、复习字段、核心章节和状态记录。
4. 复习队列、薄弱点、未完成队列只做索引视图，不复制卡片状态。
5. 今日任务是当天工作台，可以保留勾选痕迹，但不作为长期状态源。
6. 本周计划只管方向、容量、禁区和优先清理对象，不维护任务状态。
7. 学习日志只记录当天实际发生的事实、卡点、回写动作和明日建议。
8. 全局规则集中写入 `04_学习追踪/学习追踪操作手册.md`，其他模板只引用它。

## 文件职责

### 任务池

职责：保存想学但还没开始学习的候选任务。

建议字段：

```md
| 优先级 | 模块 | 想学任务 | 为什么想学 | 预计投入 | 触发条件 | 备注 |
```

不保存：

```text
状态
产出物
完成标准
未完成原因
重试日
来源今日任务
```

任务池项被真正执行前，必须先创建学习卡片。创建学习卡片并开始推进后，该任务从任务池移除。

### 本周计划

职责：提供本周方向和容量约束。

建议结构：

```md
## 本周方向
## 本周容量
## 本周优先清理
## 本周不做
## 本周候选新学
```

本周计划不维护每日任务完成状态，不保存掌握度，不保存复习日期。

### 今日任务

职责：当天工作台。

建议结构：

```md
## 今日生成依据
## 今日原则
## 今日动作
## 时间块
## 完成标准
## 日终回写清单
```

今日任务只回答今天对哪些卡片或新任务做什么动作。日终后它只作为当天计划快照，不作为事实源。

### 学习日志

职责：当天事实流水和决策记录。

建议结构：

```md
## 今日实际动作
## 今日卡点
## 日终回写
## 明日建议
```

学习日志不作为状态查询来源。AI 查询当前状态时，应读取学习卡片和队列索引，而不是从学习日志推断。

### 学习卡片

职责：唯一状态源。

学习卡片保存：

```yaml
状态: 学习中 / 未完成 / 待复习 / 需复习 / 已掌握 / 暂缓 / 拆小重试
上次复习:
下次复习:
间隔天数:
难度系数:
复习次数:
连续答对:
失误次数:
易错:
来源:
```

正文保存：

```md
## 核心章节
## 复习规则
## 状态记录
```

学习卡片按可复习知识单元创建，不按当天动作创建。

合格卡片需要满足：

1. 未来可以拿来复习。
2. 能列出 3 到 7 个核心回忆问题。
3. 如果没学完，可以明确说明差哪一步。

### 复习队列

职责：索引哪些卡片需要复习。

只保存索引特有字段：

```md
| 卡片 | 下次复习 | 触发原因 | 备注 |
```

不复制卡片状态、易错、间隔、复习次数、连续答对等字段。

### 薄弱点

职责：索引哪些卡片讲不清或容易错。

只保存索引特有字段：

```md
| 卡片 | 薄弱表现 | 优先级 | 发现日期 | 处理建议 |
```

不复制卡片状态。

### 未完成队列

职责：索引哪些卡片没有达到完成标准。

只保存索引特有字段：

```md
| 卡片 | 未完成原因 | 下一步动作 | 重试建议日 | 是否需要拆小 |
```

不复制卡片状态。

## 状态机

学习卡片状态只允许：

```text
学习中
未完成
待复习
需复习
已掌握
暂缓
拆小重试
```

状态流转：

```text
任务池项转卡 -> 学习中

学习中 -> 待复习
学习中 -> 未完成
学习中 -> 拆小重试
学习中 -> 暂缓

未完成 -> 学习中
未完成 -> 拆小重试
未完成 -> 暂缓

待复习 -> 需复习
待复习 -> 已掌握
待复习 -> 待复习

需复习 -> 待复习
需复习 -> 已掌握
需复习 -> 拆小重试

拆小重试 -> 新建更小卡片，原卡暂缓或关闭
暂缓 -> 学习中
```

关键规则：

1. 任务池项创建卡片后，初始状态为 `学习中`。
2. 初学达到完成标准后，状态变为 `待复习`，并进入复习队列。
3. 复习没答出或明显磕绊，状态变为 `需复习`，并进入薄弱点。
4. 当天没达到完成标准，状态变为 `未完成`，并进入未完成队列。
5. 连续未完成或卡片太大，状态变为 `拆小重试`。
6. 连续顺畅后，状态变为 `已掌握`。

## 今日任务生成流程

生成今日任务时，AI 必须先读取：

```text
04_学习追踪/学习追踪操作手册.md
```

再按需读取：

```text
04_学习追踪/复习队列.md
04_学习追踪/未完成队列.md
04_学习追踪/薄弱点.md
02_动态执行/任务池/任务池.md
02_动态执行/本周计划/当前周计划.md
相关学习卡片
```

选择优先级：

```text
1. 到期或逾期复习卡片
2. 未完成卡片
3. 薄弱卡片
4. 本周计划指定方向
5. 任务池未开始任务
```

硬约束：

```text
每天最多 1 个新学习任务。
新学习任务必须先转成学习卡片，再进入今日任务。
不追全部历史欠账，只恢复关键链路。
```

## 日终回写流程

日终必须按固定顺序回写：

```text
1. 更新学习卡片
2. 更新复习队列 / 薄弱点 / 未完成队列
3. 更新任务池
4. 写学习日志
5. 今日任务只保留当天快照
```

详细规则：

1. 先更新学习卡片的状态、复习字段、状态记录和今日卡点。
2. 再更新索引视图：
   - 达到复习条件的卡片进入或更新复习队列。
   - 讲不清或容易错的卡片进入薄弱点。
   - 未达到完成标准的卡片进入未完成队列。
3. 再更新任务池：
   - 只移除已经转卡并开始学习的任务。
   - 不写完成、未完成、进行中等状态。
4. 最后写学习日志：
   - 记录今日实际动作。
   - 记录卡点和决策理由。
   - 记录做过哪些回写。
   - 记录明日建议。

## 模板改造范围

方案 B 一次性重写全局协议和全部模板，但不迁移所有历史日志。

需要更新：

```text
04_学习追踪/学习追踪操作手册.md
02_动态执行/任务池/任务池.md
99_模板/任务池.md
99_模板/每日任务模板.md
99_模板/本周计划模板.md
04_学习追踪/复习队列.md
04_学习追踪/薄弱点.md
04_学习追踪/未完成队列.md
学习卡片模板或学习卡片结构说明
学习日志模板，如当前没有模板则新增
```

历史文件处理：

```text
历史今日任务、历史本周计划、历史学习日志保留为历史事实，不批量迁移。
从新模板和操作手册生效后，新生成的文件按 v2 模型执行。
```

## 验收标准

1. `学习追踪操作手册.md` 明确包含文件职责、状态机、今日生成流程和日终回写顺序。
2. `任务池.md` 只保存未开始候选任务，没有状态、未完成、复习字段。
3. 今日任务模板只作为当天工作台，不保存长期状态。
4. 本周计划模板只保存方向和容量约束。
5. 学习日志模板只记录事实、卡点、回写和明日建议。
6. 复习队列、薄弱点、未完成队列不再复制卡片状态字段。
7. 新任务进入执行前必须先创建学习卡片。
8. AI 可以只通过操作手册加状态源文件生成当天工作台。
