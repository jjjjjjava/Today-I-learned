# 03 · 爆发归因

## 目标

解释“为什么从这个时间点突然增加”，并在影响扩大时先止损。爆发归因不是看到新版本与上涨同时出现就直接归因。

## 处理链

```text
确认是真爆发
→ 找指标拐点
→ 拆出贡献增量最大的聚类
→ 圈定受影响人群
→ 对齐版本、开关、配置和服务端变更
→ 单点证据证明机制
→ 关闭或修复后的指标回落反向验证
```

## 真爆发判断

同时观察：

- 事件量；
- 受影响用户数或用户率；
- 增长是否持续；
- 上报口径和活跃用户是否变化。

一个用户短时间触发 100 次，与 100 个用户各触发一次，影响面不同。

## “茉莉奶白”案例

```text
机器人告警
→ 事件量和用户数持续上涨
→ 多维切片
→ 企业维度相对增幅最大
→ 集中“茉莉奶白”
→ 对齐近期业务开关
→ 关闭开关
→ 指标逐渐回落
```

企业集中是相关性；开关时间线、代表样本和关闭后的回落共同增强因果判断。

## 复习检查

1. 为什么只看事件量会制造“爆发幻觉”？
2. 为什么应调查贡献增量最大的聚类？
3. 什么证据能把时间相关性提升为因果判断？
