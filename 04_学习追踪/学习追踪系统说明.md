# 学习追踪系统说明

> 当前采用“方案 A”：纯 Obsidian / 对话驱动，不使用后台服务，不使用外部 CLI。状态只在主动发起“录入 / 复习 / 看状态”时推进。

## 1. 单一主线

```text
学习卡片 = 追踪单元
复习队列 -> 引用学习卡片
薄弱点 -> 引用学习卡片
未完成队列 -> 引用学习卡片
```

## 2. 卡片位置

所有卡片集中在：[[学习卡片/学习卡片索引]]

每张卡只存：

- id
- 主题
- 核心章节
- 创建日期
- 上次复习
- 下次复习
- 间隔天数
- 难度系数
- 复习次数
- 连续答对
- 失误次数
- 易错
- 来源笔记

不存知识答案。答案留在来源笔记中。

## 3. 命令语义

### 录入

创建一张学习卡片，填入核心章节线索。

### 复习

从 [[复习队列]] 找到到期卡片，逐张展示核心章节，自评后回写卡片状态。

### 看状态

统计 [[学习卡片/学习卡片索引]] 中：总卡数、今日到期、易错卡、未完成卡。

## 4. 调度规则

沿用轻量 SRS：

- 没答出：间隔回到 1 天，易错=true。
- 磕绊：间隔小幅增长。
- 顺畅：按难度系数增长。
- 易错卡连续顺畅 2 次后解除易错。
