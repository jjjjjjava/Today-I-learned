# 学习追踪系统说明

> 当前采用 v3：纯 Obsidian / 对话驱动。按能够独立失败的检索任务复习；层级负责组织，失败点负责调度。状态只在主动发起操作时推进。

## 1. 核心模型

```text
学习卡片 = 唯一状态源
任务池 = 未开始候选输入
本周计划 = 方向和容量约束
今日任务 = 当天工作台
复习队列 / 薄弱点 / 未完成队列 = 学习卡片索引视图
学习日志 = 事实流水和决策记录
```

复习对象按需使用三类，不强制每个主题拆满：

```text
知识点、阶段案例 = 自适应间隔复习
全流程模拟 = 每 7～14 天低频出现
```

## 2. 文件入口

- [[学习追踪操作手册]]：全局执行协议。
- [[学习卡片/学习卡片索引]]：学习卡片目录索引。
- [[复习队列]]：复习索引视图。
- [[薄弱点]]：薄弱索引视图。
- [[未完成队列]]：未完成索引视图。

## 3. 状态查询规则

查询当前状态时，只能以学习卡片为准。

索引文件用于快速找到相关卡片，但不作为状态源。

## 4. 默认操作入口

```text
生成今日任务 -> 先读学习追踪操作手册，再读队列、任务池和相关卡片。
录入学习卡片 -> 新任务开始学习前先卡片化。
复习完成 -> 先回写学习卡片，再更新索引视图。
标记薄弱 / 未完成 -> 先回写学习卡片，再更新对应索引。
```
