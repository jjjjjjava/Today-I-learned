# 学习追踪操作手册

## 0. 核心原则

```text
不按知识树节点复习。
按能够独立失败的检索任务复习。

层级负责组织。
失败点负责调度。
```

学习材料可以按知识点、阶段、全流程组织，但不强制每个主题拆满三层。

```text
普通知识、算法题：通常只建知识点卡。
可分段机制：按需要建立知识点卡和阶段案例卡。
项目型主题：按需要建立知识点卡、阶段案例卡、全流程模拟卡。
```

三类卡共用一套状态和队列：

```text
知识点、阶段案例：自适应间隔复习。
全流程模拟：每 7～14 天低频出现。
```

父层只保存结构、评分标准和子卡引用，不复制子层答案。同一知识点可以被多个阶段引用，因此结构不是严格树。

---

## 1. 文件职责

```text
学习卡片 = 唯一状态源
任务池 = 想学但尚未开始的候选输入
本周计划 = 方向和容量约束
今日任务 = 当天工作台
复习队列 = 到期卡片索引
薄弱点 = 失败点索引
未完成队列 = 初学未完成索引
学习日志 = 当天事实和决策流水
```

### 1.1 学习卡片

学习卡片保存检索任务、复习类型、调度状态和历史记录。答案与完整材料留在来源笔记。

一张卡必须能独立出错、独立评分、独立调整间隔。

### 1.2 任务池

只保存还没开始学习的候选任务。真正开始前先创建学习卡片，再从任务池移除。

### 1.3 本周计划

只保存本周方向、容量、优先清理项和明确不做项。不复制卡片状态和复习日期。

### 1.4 今日任务

只回答今天复习哪些卡、推进什么新学习。日终后保留计划快照，不作为长期状态源。

### 1.5 三个索引队列

- 复习队列：哪张卡、哪天到期、为什么排入。
- 薄弱点：哪张卡在哪个维度失败、失败表现是什么。
- 未完成队列：哪张卡尚未完成初学、下一步是什么。

索引不复制卡片状态、间隔、次数等字段。冲突时以卡片为准。

### 1.6 学习日志

记录当天做了什么、暴露什么失败点、回写了哪些卡、明天建议什么。不承担状态查询。

## 2. 三类检索任务

### 2.1 知识点

适合独立复习的内容：

- 容易独立忘记。
- 能独立答错。
- 面试或实践价值高。
- 连续两次成为上层任务的失败原因。

问题不以“定义是什么”为主，优先问：

```text
什么场景使用？
为什么有效？
怎样看到证据？
有什么边界或失效条件？
```

评分维度：

```text
结论、原理、证据、边界
```

### 2.2 阶段案例

阶段案例用于练因果链、工具使用和组合能力。项目阶段、机制阶段都可归入此类。

必须使用案例、异常现象或约束变化提问，不背固定段落。

示例：

```text
冷启动 P95 上涨 120ms。Trace 没有单个长任务，
但有多个 10～20ms 初始化任务。如何定位、归因、治理、验证？
```

评分维度：

```text
因果、证据、代码、方案
```

### 2.3 全流程模拟

全流程模拟接近真实面试使用形式，用于检查零件能否组装成完整回答。

示例：

```text
完整讲述首页启动优化：
线上发现、线下定位、代码归因、方案、验证、回归、灰度、预算回填。
```

完成主述后随机追问，不固定背诵顺序。

评分维度：

```text
结构、归因、权衡、验证、闭环
```

全流程卡只保存叙事骨架、评分标准、关联阶段和知识点链接，不复制子卡内容。

## 3. 何时建卡

不要把每个目录、标题、概念自动变成卡片。

满足任一条件才建独立卡：

1. 内容重要，值得长期保持可提取。
2. 同一失败点连续两次导致阶段或全流程失败。

新卡还必须通过三个检查：

```text
能否独立提问？
能否独立判错？
失败后是否只需调整它，而不必重置整组内容？
```

任一答案为否，不独立建卡；留在上层卡的结构或评分标准中。

拆卡不是复制答案。来源笔记保存知识内容，学习卡片只保存检索问题、评分标准、状态和记录。

## 4. 统一卡片结构

```yaml
type: learning-card
id: 卡片唯一名
主题: 大主题/子主题
复习类型: 知识点 / 阶段案例 / 全流程模拟
所属主题: 首页启动优化
创建日期: YYYY-MM-DD
上次复习: YYYY-MM-DD 或 null
下次复习: YYYY-MM-DD
间隔天数: 1
复习次数: 0
连续答对: 0
失误次数: 0
易错: false
状态: 学习中 / 未完成 / 待复习 / 暂缓
来源: [[来源笔记]]
```

正文至少包含：

```md
## 检索任务

- 能独立判断对错的问题

## 评分标准

- 当前复习类型对应的评分维度

## 状态记录

| 日期 | 动作 | 自评 | 失败维度 | 间隔天数 | 下次复习 | 状态变化 | 备注 |
```

不再使用 `难度系数`。旧卡中的该字段不参与调度，之后修改旧卡时顺手删除，不批量迁移。

旧卡缺少 `复习类型` 和 `所属主题` 时，先根据实际检索形式判断；修改该卡时再补字段，不为迁移制造额外复习任务。

## 5. 状态机

只保留四个状态：

```text
学习中
未完成
待复习
暂缓
```

流转规则：

```text
任务池转卡 -> 学习中
学习中完成 -> 待复习
学习中未完成 -> 未完成
未完成继续学习 -> 学习中
任意有效卡暂停 -> 暂缓
暂缓恢复 -> 学习中或待复习
```

复习答错不创建新状态。卡片仍为 `待复习`，通过失败维度、间隔和薄弱点索引表达。

不使用：

- `需复习`：与下次复习日期和薄弱点重复。
- `已掌握`：到 60 天仍需低频提取。
- `拆小重试`：这是动作。拆卡后原卡设为 `暂缓`。

## 6. 调度规则

### 6.1 知识点与阶段案例

共用间隔阶梯：

```text
1 / 3 / 7 / 14 / 30 / 60 天
```

初学完成后，默认次日首复，间隔为 1 天。

复习结果：

```text
顺畅：升一档。
磕绊：停留当前档。
没答出：降到 1 天。
```

具体处理：

- 更新 `上次复习`、`下次复习`、`间隔天数`、次数和状态记录。
- `磕绊` 或 `没答出` 必须记录具体失败维度和失败表现。
- `没答出` 时设置 `易错: true`，加入薄弱点。
- 到 60 天后，顺畅仍保持 60 天。
- 子卡结果只改变该卡，不联动重置父卡或兄弟卡。

### 6.2 全流程模拟

默认每 14 天一次；需要加强表达时改为 7 天。

```text
具体知识点失败：
  提前对应知识点卡；全流程保持 14 天。

某个阶段组合失败：
  提前对应阶段案例；全流程保持 14 天。

知识都懂，但结构、表达、权衡或闭环混乱：
  全流程改为 7 天；不新增知识卡。
```

全流程失败必须先定位缺口，禁止重置全部子卡。

### 6.3 批量导入

批量拆出的旧知识不等于当天新学。允许按每日容量错峰首复，但不能因为目录拆分而把所有节点都加入队列。

## 7. 评分规则

总体结果仍用三档：

```text
顺畅：关键维度完整、正确，能直接用于面试或实践。
磕绊：核心结论正确，但一至两个维度缺失、迟疑或证据不足。
没答出：核心结论错误、主因果链断裂，或关键维度缺失一半以上。
```

评分时同时记录具体维度：

```text
知识点：结论 / 原理 / 证据 / 边界
阶段案例：因果 / 证据 / 代码 / 方案
全流程模拟：结构 / 归因 / 权衡 / 验证 / 闭环
```

只写“磕绊”不算完成记录。必须补充类似：

```text
失败维度：代码
失败表现：能读 Trace，但无法映射到具体初始化调用点。
```

## 8. 今日任务生成

读取顺序：

```text
1. 本手册
2. 本周计划
3. 复习队列
4. 未完成队列
5. 薄弱点
6. 任务池
7. 候选学习卡片
```

每日复习容量：

```text
知识点：6～10 张
阶段案例：1 张
全流程模拟：到期时 1 次，每 7～14 天
新学习任务：最多 1 个
```

全流程模拟到期时，替代当天阶段案例，避免叠加重任务。

到期卡超过容量时，按以下顺序选择：

1. 最近模拟或阶段案例暴露的失败点。
2. 本周主线中的到期卡。
3. 高价值、易错、重复失败卡。
4. 其他到期卡，按逾期时间排序。

未到期卡不为凑数量提前复习。到期卡不足时也不强行补满。

不清空全部历史欠账。每日容量是硬上限，旧账不能永久挤掉本周主线。

---

## 9. 失败路由

核心规则：

```text
层级负责组织；失败点负责调度。
```

例：

```text
全流程忘记 ContentProvider：
  记录全流程的失败维度。
  提前 ContentProvider 知识点卡。
  不重置整个启动阶段。

Trace 会看，但无法归因到代码：
  提前“Trace 到代码归因”阶段案例。
  不重置 Trace 基础知识卡。

知识都懂，但回答顺序混乱：
  全流程模拟改为 7 天。
  不新增知识点卡。
```

父卡记录这次诊断结果，不复制子卡状态。

---

## 10. 日终回写

固定顺序：

```text
1. 更新学习卡片。
2. 更新复习队列、薄弱点、未完成队列。
3. 更新任务池。
4. 写学习日志。
5. 今日任务保留当天快照。
```

回写要求：

1. 先写卡片的结果、失败维度、间隔、下次复习和状态记录。
2. 再同步索引。
3. 只有真正开始学习后，才从任务池移除候选任务。
4. 全流程失败先完成失败路由，再更新各自日期。

## 11. 常用口令

```text
生成今日任务。

录入学习卡片：
来源、卡片 id、主题、复习类型、所属主题、检索任务、评分标准。

开始复习。

复习完成：
[[卡片路径]]
自评：顺畅 / 磕绊 / 没答出
失败维度：无 / 具体维度
失败表现：具体缺口

开始全流程模拟：[[卡片路径]]

标记未完成：
[[卡片路径]]
原因：具体原因
下一步：继续 / 拆小 / 暂缓

看学习追踪状态。
按学习追踪操作手册处理。
```

## 12. 默认规则

- 日期以系统当前日期为准。
- 新学完成的知识点和阶段案例默认次日首复。
- 全流程模拟默认 14 天；表达结构失败时改为 7 天。
- 状态只在用户主动发起操作时推进，不后台提醒。
- 不因目录层级自动建卡。
- 不因父层失败重置全部子卡。
- 不为清空逾期队列突破每日容量。
