# 学习追踪操作手册

> 这是复习卡片系统的简化操作说明。  
> 以后只要说“按学习追踪操作手册处理”，就默认使用这里的规则。

---

## 0. 核心原则

```text
一张学习卡片 = 一篇笔记 / 一个章节 / 一个待追踪任务。
卡片只存学习状态和核心章节线索，不存答案。
答案和细节留在来源笔记里。
状态只在我主动发起命令时推进，不后台提醒。
```

主线关系：

```text
学习卡片 = 单一追踪单元
复习队列 -> 引用学习卡片
薄弱点 -> 引用学习卡片
未完成队列 -> 引用学习卡片
```

---

## 1. 文件位置

### 学习卡片

所有卡片放在：

- [[学习卡片/学习卡片索引]]

可按主题分目录，例如：

```text
学习卡片/OpenGL/01_渲染管线.md
学习卡片/ANR/ANR_治理骨架v0.md
学习卡片/启动优化/冷启动五阶段链路.md
```

### 队列文件

- [[复习队列]]：今天 / 近期要复习哪些卡片。
- [[薄弱点]]：哪些卡片讲不清、容易错。
- [[未完成队列]]：哪些卡片还没有推进到完成标准。

---

## 2. 卡片结构

每张卡片必须包含这些字段：

```yaml
type: learning-card
id: 卡片唯一名
主题: 大主题/子主题
创建日期: YYYY-MM-DD
上次复习: YYYY-MM-DD 或 null
下次复习: YYYY-MM-DD
间隔天数: 整数
难度系数: 2.5
复习次数: 0
连续答对: 0
失误次数: 0
易错: false
状态: 待复习 / 需复习 / 已掌握 / 未完成 / 拆小重试
来源: [[来源笔记]]
```

正文只保留：

```md
## 核心章节

- 核心问题 1
- 核心问题 2
- 核心问题 3

## 复习规则

看核心章节 -> 凭记忆回顾 -> 回来源笔记核对 -> 整张卡自评。

## 状态记录

| 日期 | 自评 | 间隔天数 | 下次复习 | 备注 |
```

## 3. 你可以怎么跟我说

### A. 新学习了一个知识点

推荐说法：

```text
录入学习卡片：
来源：[[笔记路径]]
卡片id：xxx
主题：xxx/xxx
核心章节：
1. xxx？
2. xxx？
3. xxx？
```

我会做：

1. 创建学习卡片。
2. 设置初始 SRS 字段：
   - 创建日期 = 今天
   - 上次复习 = null
   - 间隔天数 = 1
   - 下次复习 = 明天
   - 难度系数 = 2.5
   - 复习次数 = 0
   - 连续答对 = 0
   - 失误次数 = 0
   - 易错 = false
3. 加入 [[学习卡片/学习卡片索引]]。
4. 加入 [[复习队列]]。

---

### B. 要开始复习

推荐说法：

```text
开始复习，按学习追踪操作手册处理。
```

或者：

```text
复习今天到期卡片。
```

我会做：

1. 从 [[复习队列]] 找 `下次复习 <= 今天` 的卡片。
2. 一次给你一张卡。
3. 只展示：卡片标题 + 核心章节。
4. 你凭记忆回顾，再自己回来源笔记核对。
5. 你告诉我自评：
   - 没答出
   - 磕绊
   - 顺畅
6. 我更新卡片状态和下次复习日期。
7. 继续下一张。
8. 最后给今日复习小结。

---

### C. 完成了一张卡的复习

推荐说法：

```text
复习完成：[[学习卡片/xxx]]
自评：顺畅 / 磕绊 / 没答出
卡点：xxx
```

我会按调度算法更新：

#### 没答出

```text
复习次数 += 1
上次复习 = 今天
失误次数 += 1
连续答对 = 0
难度系数 = max(1.3, 难度系数 - 0.20)
间隔天数 = 1
易错 = true
下次复习 = 今天 + 1 天
```

#### 磕绊

```text
复习次数 += 1
上次复习 = 今天
连续答对 += 1
难度系数 = max(1.3, 难度系数 - 0.15)
间隔天数 = min(90, max(1, round(旧间隔 * 1.2)))
下次复习 = 今天 + 间隔天数
```

#### 顺畅

```text
复习次数 += 1
上次复习 = 今天
连续答对 += 1
难度系数不变
间隔天数 = min(90, round(旧间隔 * 难度系数))
如果 易错 == true 且 连续答对 >= 2，则 易错 = false
下次复习 = 今天 + 间隔天数
```

---

### D. 发现某个知识点薄弱

推荐说法：

```text
标记薄弱：[[学习卡片/xxx]]
表现：xxx 讲不清 / 容易混
```

我会做：

1. 更新该卡片：
   - 状态 = 需复习
   - 易错 = true
2. 加入 [[薄弱点]]。
3. 确认是否已在 [[复习队列]]，没有就补上。

如果没有对应卡片，我会先创建卡片。

---

### E. 某个任务没完成

推荐说法：

```text
标记未完成：[[学习卡片/xxx]]
原因：xxx
下一步：拆小 / 明天继续 / 暂缓
```

我会做：

1. 更新该卡片状态：未完成 / 拆小重试。
2. 加入 [[未完成队列]]。
3. 如果连续未完成，拆小核心章节，而不是新增散落任务。

---

### F. 看当前状态

推荐说法：

```text
看学习追踪状态。
```

我会统计：

- 总学习卡片数。
- 今天到期卡片数。
- 易错卡片。
- 未完成卡片。
- 最近 7 天要复习的卡片。

## 4. 简化口令

你以后可以直接用这些短句：

```text
录入学习卡片：...
开始复习。
复习完成：... 自评：顺畅。
标记薄弱：...
标记未完成：...
看学习追踪状态。
按学习追踪操作手册处理。
```

---

## 5. 默认日期规则

- 今天日期以系统当前日期为准。
- 新卡默认明天复习。
- 不后台提醒，只在你主动发起命令时推进。

---

## 6. 默认复习评分口径

```text
顺畅：核心章节基本都能秒答且正确。
磕绊：漏一个点，或有些点想半天。
没答出：整张卡想不起来，或漏一半以上。
```

---

## 7. 对我的要求

当用户提到学习卡片、复习、薄弱点、未完成、看状态时：

1. 优先读取本手册。
2. 再读取相关卡片 / 队列。
3. 只推进用户主动要求的状态。
4. 不把答案写进卡片。
5. 所有队列都以学习卡片链接为主线。
6. 修改后必须验证文件写入。
