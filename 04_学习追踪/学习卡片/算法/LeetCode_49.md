# LeetCode_49

> 主题：算法/哈希与字符串（字母异位词分组）

## 核心章节

- 为什么字母异位词可以用“排序后的字符串”作为 key？
- 如果不用排序，如何用 26 位字符计数作为 key？
- HashMap 的 key 到 List 的分组过程怎么写？
- 空字符串、单字符、重复字符串这些边界如何处理？
- 排序 key 和计数 key 的时间复杂度分别是什么？
- Java 返回结果为什么是 `new ArrayList<>(map.values())`，而不是 `new List<>(...)` 或 `map.valuesSet()`？
