# 完整的启动优化治理体系

> 主题：启动优化/完整治理体系
> 来源：[[../../../03_知识资产/项目/首页启动优化/00_完整的启动优化治理体系]]

## 核心章节

- 启动优化为什么要分成“存量优化”和“增量劣化治理”两条线？
- 增量治理的五层防线是什么：Lint、CI Benchmark、候选版本自动化性能测试、灰度对比、线上长尾监控？
- 存量优化如何走“发现 -> 归因 -> 治理 -> 验证 -> 新基线回填”闭环？
- 为什么用多轮 Benchmark 选择中位数轮次，再用 Perfetto 解释根因？
- 为什么必须同时验证性能、Trace 假设和功能安全？
- 新稳定基线和 Stage / Task 预算怎样进入下一轮增量治理？
