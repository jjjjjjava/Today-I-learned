# 启动优化方法论

> 主题：启动优化/方法论
> 来源：[[../../../03_知识资产/项目/启动优化方法论/syllabus]]
> 说明：本卡记录启动优化的统一治理方法论：增量劣化治理、存量启动优化、指标口径、归因链路和验证沉淀。

## 核心章节

- 启动优化为什么要分成“存量优化”和“增量劣化治理”两条线？
- 冷启动、温启动、热启动、TTID、TTFD、P50、P90、超时率、样本量分别解决什么问题？
- 如何把总启动耗时拆成 Stage / Task 观测树？
- 增量治理的五层防线是什么：Lint、CI Benchmark、候选版本自动化性能测试、灰度对比、线上长尾监控？
- 存量优化如何走“发现 -> 归因 -> 治理 -> 验证 -> 新基线回填”闭环？
- 如何沿版本、场景、设备档位、Stage、Task 缩小范围，再用 Macrobenchmark / Perfetto 解释根因？
- 治理手段如何选择：删除、缩短、移出关键路径、重排并发、降级？
