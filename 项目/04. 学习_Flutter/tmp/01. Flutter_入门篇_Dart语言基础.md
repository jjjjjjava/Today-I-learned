## 03.原理机制

### 3.1 函数

可选参数

- Dart 的函数参数分为**必须参数**（默认需传递）和**可选参数**，可选参数又分两种：

- 位置可选参数：

  - 使用方括号`[]`包裹，按位置传递

  - 可添加`?`标记为可空类型（允许不传递）

  - 参数的匹配依赖于 “传递顺序”，必须按函数定义时的参数位置依次传递。

  - ```
    // 位置可选参数示例：gender为可选参数
    void greet(String name, [String? gender]) {
      if (gender != null) {
        print("Hello $gender $name");
      } else {
        print("Hello $name");
      }
    }
    
    // 调用时，第一个参数必须是name，第二个（如果传）必须是gender，按位置匹配
    greet("小明");       // 正确：第一个参数匹配name
    greet("小红", "Miss"); // 正确：第一个匹配name，第二个匹配gender
    ```

- 命名可选参数：

  - 使用大括号`{}`包裹，通过名称传递

  - 参数的匹配依赖于 “参数名称”，传递时必须显式指定参数名，与顺序无关。

  - ```
    // 命名可选参数示例：name为必须参数，age为可选参数
    void introduce({required String name, int? age}) {
      print("My name is $name, and I'm $age years old");
    }
    
    // 调用时必须指定参数名，顺序可以任意
    introduce(name: "杰哥"); // 正确：通过name匹配
    introduce(age: 20, name: "小花"); // 正确：顺序无关，通过名称匹配
    ```

空值处理操作符

- `?`：可选调用，对象为 null 时不执行后续操作

  - ```
    String? text;
    int? length = text?.length; // text为null时，length也为null（不报错）
    ```

- `??`：空值合并，左侧为 null 时使用右侧默认值

  - ```
    int? a;
    int b = a ?? 0; // a为null时，b=0
    ```

- `??=`：空值赋值，变量为 null 时才赋值

  - ```
    String? name;
    name ??= "默认名称"; // name为null，赋值为"默认名称"
    name ??= "新名称"; // name已赋值，不执行
    ```

函数作为参数传递

- 函数可作为参数传入另一个函数：

  - ```
    // 定义一个接收函数参数的方法
    void performOperation(int a, int b, Function operation) {
      var result = operation(a, b);
      print("运算结果：$result");
    }
    
    // 定义具体运算函数
    int sum(int x, int y) => x + y;
    int difference(int x, int y) => x - y;
    
    // 调用示例
    performOperation(10, 5, sum); // 输出：运算结果：15
    performOperation(10, 5, difference); // 输出：运算结果：5
    ```

- Kotlin 中 lambda 会被编译为`FunctionN`接口的实现类对象，Dart 中函数直接作为`Function`类型对象存在，二者本质一致：都是将函数逻辑封装为对象，传递对象引用，调用时执行对象关联的函数体。
