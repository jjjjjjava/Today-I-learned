# Android 面试知识库

## What This Is

一个系统化的 Android 开发知识库，用于整理学习笔记、跟踪技术知识点掌握情况。面向有一定 Android 工作经验的开发者，目标是通过结构化学习覆盖大厂/中厂面试所需的核心知识体系。

## Core Value

**让每个技术点都有深度可查阅的笔记**——面试前能快速复习，工作中能随时查询原理。

## Context

- **当前状态**：在职备战跳槽，利用业余时间学习，时间有限需要高效
- **目标公司**：大厂（字节/腾讯/阿里等）+ 中厂/独角兽
- **已有积累**：已有部分音视频、OpenGL、Flutter、鸿蒙、性能优化笔记（见 `04. 学习_*` 目录）
- **面试深度要求**：大厂面试需要原理 + 源码级别的理解，不能停留在"会用"层面
- **技术背景**：有音视频（FFmpeg）、巡店视频、业务开发实战经验

## Constraints

- **时间**：在职学习，每天学习时间有限，需要优先覆盖高频考点
- **深度**：每个知识点需要达到"能讲清楚原理"的程度，而不是仅列出 API
- **结构**：笔记需要有统一格式，方便后期快速复习（参考 `00.标准化/` 下的模板）
