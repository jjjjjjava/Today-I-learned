#### **#1 获取NVR类型**





```
GET /ovopark-device/devices/getParentNvrType?devicesId=5180682
耗时: 45ms | 响应: 388B
```

**作用**: 查询设备的NVR类型（0:未知 1:v5 2:v7 3:宇视）
**调用位置**: 判断设备所属录像机类型，影响后续协议选择

#### **#7 获取播放流 ⭐核心**





```
POST /ovopark-device/video/startNewMediaPlay
耗时: 658ms | 响应: 1017B
```

**作用**: 获取设备直播流地址（FLV/RTSP/HLS等）
**返回数据**: 

FR3Data



- `flv`: FLV流地址
- `rtsp`: RTSP流地址（H.265）
- `sessionId`: 会话ID
- `vencodingname`: 编码格式

**调用代码**:

kotlin





```
@VideoPlayUtils.kt#1364

```

#### **#8 获取设备配置 ⭐核心**





```
GET /ovopark-device/video/getRvc?devicesId=5180682
耗时: 114ms | 响应: 1524B
```

**作用**: 获取设备RVC配置（能力集）
**返回数据**: 

RvcVo (50+字段)



- `thirdPartType`: 设备类型
- `ysToken/ysAppKey`: 萤石认证
- `deviceToken`: 悠络客认证

**调用代码**:

