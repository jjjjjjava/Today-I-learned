## 一、扫码支付流程（QR）

```
用户点击下单 → 创建订单 → 扫描付款码 → 提交扫码内容 → 轮询查询状态 → 显示取餐码
```

### 1. 创建订单

- **入口**：[payment_demo_page.dart:29-71](vscode-webview://0nnpjt7nt1kfl1gut1id93ffvbmva2faotj55927s2v76sjnb9gj/lib/features/payment/presentation/pages/payment_demo_page.dart#L29-L71) 用户点"点击下单"

- **状态机**：[payment_provider.dart:88-111](vscode-webview://0nnpjt7nt1kfl1gut1id93ffvbmva2faotj55927s2v76sjnb9gj/lib/features/payment/presentation/providers/payment_provider.dart#L88-L111) `PaymentNotifier._handleClickOrderButton()`

- 接口：

  ```
  POST /ovopark-dining-service/order/createOrder/v2
  ```

  - 入参：`depId / diningType / totalAmount / totalQuantity / customerPhone / orderGoodsList`
  - 出参：`orderSn`（订单号）

### 2. 扫码 & 调用聚合支付

- **入口**：扫码完成回调 → Intent `ScanQRCodeSuccess(code, type)`

- **状态机**：[payment_provider.dart:131-177](vscode-webview://0nnpjt7nt1kfl1gut1id93ffvbmva2faotj55927s2v76sjnb9gj/lib/features/payment/presentation/providers/payment_provider.dart#L131-L177) `PaymentReady → PaymentProcessing`

- 接口：

  ```
  POST /ovopark-dining-service/trade/pay/agg-pay
  ```

  - 入参：`{ "orderNo": "订单号", "authCode": "付款码" }`
  - 数据源：[payment_api_datasource.dart:49-75](vscode-webview://0nnpjt7nt1kfl1gut1id93ffvbmva2faotj55927s2v76sjnb9gj/lib/features/payment/data/datasources/payment_api_datasource.dart#L49-L75)

### 3. 轮询支付状态（关键）

- **接口**：`GET /ovopark-dining-service/trade/pay/status?orderNo={orderSn}`
- 轮询策略（process_payment_usecase.dart:104-209）：
  - 前 10 秒：每秒 1 次（共 10 次）
  - 10 秒后：指数退避 1s → 2s → 4s → 8s → 16s
  - 总超时：**2 分钟**
- **响应**：`status` 字段，`1=支付中 / 2=成功 / 3=失败`，成功时返回 `pickupCode`（取餐码）
- **退出条件**：成功/失败立即返回；processing 继续；超时再请求一次后失败返回

### 4. 结果处理

- 成功 → `PaymentSuccess` 状态，弹 `PaymentSuccessOverlay` 展示取餐码
- 失败 → `PaymentFailed` 状态，可重试

## 二、现金支付流程（CASH）

**现金支付和扫码支付共用同一个下单流程**，订单在「用户选择支付方式之前」就已经创建好了

```
用户输入金额 → 金额校验 → 调现金支付接口 → 轮询查询状态 → 计算找零 → 显示取餐码
```

### 1. 金额校验

- **UI**：[cash_payment_view.dart](vscode-webview://0nnpjt7nt1kfl1gut1id93ffvbmva2faotj55927s2v76sjnb9gj/lib/features/payment/presentation/widgets/cash_payment_view.dart) 收银员输入实收金额

- 校验：payment_provider.dart:180-252 

  ```
  _handleConfirmCashPayment()
  ```

  - `输入金额 < 应收金额` → `PaymentAmountValidationError`，提示"输入金额需大于应收，请重新输入"
  - 金额合法 → 进入支付流程

### 2. 调用现金支付接口

- 接口：

  ```
  POST /ovopark-dining-service/trade/pay/cash-pay
  ```

  - 入参：`{ "orderNo": "订单号", "receivedAmount": 应收金额 }`
  - **注意**：传给后端的是**应收金额**，不是用户输入金额（找零本地算）
  - 数据源：[payment_api_datasource.dart:107-133](vscode-webview://0nnpjt7nt1kfl1gut1id93ffvbmva2faotj55927s2v76sjnb9gj/lib/features/payment/data/datasources/payment_api_datasource.dart#L107-L133)

### 3. 轮询支付状态

- **复用扫码支付的同一个轮询方法** `pollPaymentStatus(orderSn)`，策略完全一致（前 10s 每秒一次，之后指数退避，2 分钟超时）

### 4. 找零 & 结果

- 成功（payment_provider.dart:227-240）：
  - `changeAmount = 用户输入金额 - 应收金额`
  - `> 0`：显示"还需找零 X 元"
  - `= 0`：显示"支付成功"
  - 显示取餐码，3 秒倒计时自动关闭
- 失败 → 错误提示，可重试

## 三、共同点对比

| 维度         | 扫码支付                              | 现金支付              |
| ------------ | ------------------------------------- | --------------------- |
| 创建订单接口 | 同一个 `/order/createOrder/v2`        | 同一个                |
| 支付接口     | `/trade/pay/agg-pay`                  | `/trade/pay/cash-pay` |
| 状态查询接口 | `/trade/pay/status`                   | 同一个                |
| 轮询策略     | 前 10s 每秒、之后指数退避、2 分钟超时 | **完全一致**          |
| 特殊逻辑     | 需要付款码 `authCode`                 | 金额校验 + 找零计算   |

## 四、状态机（7 个状态）

`PaymentInitial → PaymentLoading → PaymentReady → PaymentProcessing → PaymentSuccess / PaymentFailed` （现金支付额外分支：`PaymentReady → PaymentAmountValidationError → PaymentReady`）
