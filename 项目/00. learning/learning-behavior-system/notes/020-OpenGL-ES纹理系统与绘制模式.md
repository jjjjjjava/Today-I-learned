## 1. 纹理三件套

### 一句话本质
片元着色器采样需要纹理资源，GPU 通过"插槽+类型+对象"三层结构管理纹理访问。

### 底层机制
- **纹理对象**：GPU 显存中图像数据的句柄（整数 ID）
  - `glGenTextures` → 仅从 ID 池分配号码，无显存
  - `glTexImage2D` → 才真正分配显存并上传数据
- **纹理单元**：GPU 固定入口插槽，着色器只认插槽不认对象
  - `glActiveTexture(GL_TEXTURE0)` = 选中 0 号插槽
- **纹理目标**：插槽的类型声明
  - `GL_TEXTURE_2D` → 普通图片
  - `GL_TEXTURE_EXTERNAL_OES` → 视频帧（OES 外部纹理）
  - `glBindTexture(目标, ID)` = 把 ID 纹理以该类型挂到当前插槽

### 核心类比
纹理单元 = USB 口，纹理目标 = 口的类型（A/C），纹理对象 = U 盘。
着色器只认"0号口插着什么"，不直接认 U 盘。

### 面试 Q&A
**Q：glGenTextures 之后 GPU 显存里有图像数据吗？**
A：没有，只分配了 ID。调用 `glTexImage2D` 上传数据时才分配显存。

**Q：为什么需要纹理单元，不能让着色器直接访问纹理对象 ID 吗？**
A：GPU 硬件设计上着色器只能访问固定的采样器槽位（纹理单元），通过插槽隔离可以同时绑定多张纹理，避免频繁切换，提高并行效率。

## 2. 纹理工作流5步

### 一句话本质
把 CPU 的 Bitmap 搬到 GPU 显存，并配置读取规则，共5步：申请→选槽→挂载→配参→上传。

### 5步流程
```
① glGenTextures(1, ids)           从 ID 池取号，无显存，仅占用 ID
② glActiveTexture(GL_TEXTURE0)    选中目标纹理单元（后续操作锁定此槽）
③ glBindTexture(GL_TEXTURE_2D, id) 把纹理 ID 挂到当前槽的目标类型上
                                    此后 配参/上传 都作用于这个纹理
④ glTexParameteri(...)            配置采样规则（过滤方式、边界处理）
⑤ glTexImage2D(...)               分配显存 + 复制 Bitmap 像素数据
```

### 关键顺序规则
`glBindTexture` 作用于"当前激活的纹理单元"，必须先 ② ActiveTexture，再 ③ BindTexture，否则 Bind 落到错误的槽。

### 面试 Q&A
**Q：glGenTextures 和 glTexImage2D 都和纹理创建有关，区别是什么？**
A：`glGenTextures` 只分配 ID（无显存）；`glTexImage2D` 才真正分配显存并上传像素数据。

**Q：glActiveTexture 和 glBindTexture 顺序能否调换？**
A：不能。`glBindTexture` 作用于当前激活单元，必须先 Active 再 Bind，否则绑定落到错误的纹理单元上。

## 3. 绘制模式

### 一句话本质
三种模式区别只在于顶点复用策略，复用越多传给 GPU 的数据越少。

### 三种模式
| 模式 | 复用规则 | 画N个三角形需要的顶点数 | 适用场景 |
|------|---------|----------------------|---------|
| GL_TRIANGLES | 无复用，每3个顶点独立 | 3N | 通用 |
| GL_TRIANGLE_STRIP | 复用前2个顶点 | N+2 | 矩形/视频渲染 |
| GL_TRIANGLE_FAN | 共享第1个顶点 | N+2 | 扇形/圆形 |

### 矩形示例（GL_TRIANGLE_STRIP）
```
顶点：v1(左上) → v2(左下) → v3(右上) → v4(右下)
三角形：(v1,v2,v3) + (v2,v3,v4) = 完整矩形
```

### 面试 Q&A
**Q：为什么渲染视频画面选 GL_TRIANGLE_STRIP 而不是 GL_TRIANGLES？**
A：矩形只需4个顶点而非6个，减少顶点数据传输量；语义更清晰，代码更简洁。

## 4. 坐标顺序陷阱

### 一句话本质
GPU 按数组索引逐一配对顶点坐标和纹理坐标，顺序错位 = 图像变形/颠倒。

### 配对规则
```
顶点[0] ↔ 纹理[0]
顶点[1] ↔ 纹理[1]
顶点[2] ↔ 纹理[2]
顶点[3] ↔ 纹理[3]
```

### 标准矩形配对
```
顶点坐标            纹理坐标
左上  (-1,  1)  ↔  (0, 0)  纹理左上
左下  (-1, -1)  ↔  (0, 1)  纹理左下
右上  ( 1,  1)  ↔  (1, 0)  纹理右上
右下  ( 1, -1)  ↔  (1, 1)  纹理右下
```

### ⚠️ 易错点
纹理坐标不能按"直觉顺时针"写，必须严格与顶点顺序一一对应。
顺序错位 → 对角翻转/图像变形。

### 面试 Q&A
**Q：为什么纹理显示出来是颠倒的？**
A：最常见原因是顶点坐标与纹理坐标的顺序没有一一对应，光栅化插值时建立了错误的映射关系，导致图像翻转。
