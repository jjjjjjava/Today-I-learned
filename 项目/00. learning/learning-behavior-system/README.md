# Learning Operating System v1.0

面向 Android 工程师的长期学习行为管理系统。

## 这是什么？

这不是一个知识管理系统，而是一个**学习行为状态机**。它管理：
- 记忆强度的衰减
- 遗忘风险的预警
- 认知负债的累积
- 核心知识的偏置权重

## 快速开始

### 1. 安装 Skill

将 `learning-system/` 目录放到你的 `.kiro/steering/` 目录下（或其他 AI 的 skill 目录）。

### 2. 新增第一个知识点

对 AI 说：
```
新增知识点：Android 生命周期
```

AI 会询问分类、重要性、是否核心，确认后创建状态文件。

### 3. 每天询问任务

每天对 AI 说：
```
今天该干嘛？
```

AI 会根据复习到期时间、最近考核表现、核心程度、重要性等生成最多 3 个任务。

### 4. 完成学习后更新

学习后对 AI 说：
```
Android生命周期 提升到 level 3
```

AI 会检验你的理解（追问若干问题），确认达标后更新状态。

### 5. 完成复习后更新

复习后对 AI 说：
```
Android生命周期 仅复习
```

AI 会先做简短检验，再按你的回答表现动态更新复习阶段和下次复习日期。

## 目录结构

```
learning-system/
├── SKILL.md              # AI 的操作手册
├── states/               # 状态管理（AI 读写）
│   ├── pool/            # 待规划知识点
│   ├── active/          # 正在提升等级的知识点
│   ├── review/          # 进入复习周期的知识点
│   └── mastered/        # 稳定掌握
├── notes/               # 学习笔记（你自由管理）
├── meta.md              # 学习方法反思与系统调整记录
└── README.md            # 本文件
```

## 核心概念

### Level（掌握等级）

```
0 = 未接触
1 = 熟悉（看过）
2 = 理解概念
3 = 能完整讲清楚
4 = 面试可稳定回答
```

### 复习周期

`review_stage` 只提供基准间隔：

```
Stage 0 → 基准 1天
Stage 1 → 基准 3天
Stage 2 → 基准 7天
Stage 3 → 基准 14天
Stage 4 → 基准 30天
```

实际 `next_review` 会根据以下因素动态调整：
- 最近一次考核结果：`fail | weak | pass | good | excellent`
- 连续通过/失败次数
- 当前稳定度 `stability_score`
- 是否核心知识点、重要性高低

### 状态转移

```
pool (待规划)
  ↓ 开始学习
active (正在提升)
  ↓ 达到 level 4
review (复习中)
  ↓ review_stage >= 4
mastered (稳定掌握)
```

## 常用命令

- `今天该干嘛？` - 生成每日任务
- `新增知识点：XXX` - 创建新知识点
- `XXX 提升到 level N` - 提升等级（带检验）
- `XXX 仅复习` - 完成复习
- `跳过今日任务` - 拒绝建议（会提示影响）

## 设计原则

1. **状态与内容分离** - 状态文件独立于学习笔记
2. **动态复习调度** - 简单但不死板
3. **AI 可替换** - 任何 AI 读取 SKILL.md 后都能执行
4. **用户有最终决策权** - AI 提供建议，你决定
5. **防止等级虚高** - AI 会检验你的理解

## 学习债务

超过 7 天未复习，或连续两次考核不稳定的知识点视为"学习债务"。每日任务会提醒你：
- 当前债务数量
- 最久未复习的知识点
- 核心知识点是否超期

## 高级用法

### 手动编辑状态文件

你可以直接编辑 `states/` 下的 yaml 文件，AI 会读取最新内容。

### 调整系统参数

在 `meta.md` 中记录你的调整想法，AI 会读取并参考。

### 批量操作

一次性处理多个知识点：
```
Android生命周期 提升到 level 3
Kotlin协程 仅复习
新增知识点：ViewModel 原理
```

## 注意事项

- `states/` 目录由 AI 管理，不要手动移动文件（除非你知道自己在做什么）
- `notes/` 目录完全由你管理，AI 不会读取
- 序号永远递增，不重复使用
- 状态转移时，AI 会明确告知文件移动

## 长期使用建议

1. 每天早上询问"今天该干嘛？"
2. 学习后及时更新状态
3. 定期在 `meta.md` 中反思学习方法
4. 用 Git 管理整个目录，追踪学习历史
5. 核心知识点优先，避免贪多
