# 学习规划系统 - 使用指南

**创建日期：** 2025-12-24  
**适用对象：** Android开发工程师

---

## 🚀 快速开始

### 第一步：制定季度目标（每季度初）
1. 打开 `2025-Q1-目标.md`
2. 填写本季度的核心目标和里程碑
3. 确定时间分配比例

### 第二步：制定周计划（每周日晚）
1. 复制 `周计划-模板.md`，重命名为 `第X周计划-YYYY.MM.DD.md`
2. 根据季度目标，分解本周具体任务
3. 将任务分配到每一天

### 第三步：每日执行与记录
1. 在 `项目/00. 个人工作日志/周报` 中记录每日完成情况
2. 在对应的追踪文件中更新进度：
   - 算法：更新 `算法刷题记录.md`
   - Flutter：更新 `三方库学习清单.md`
   - 知识盲区：更新 `八股文复习计划.md`
   - 项目回顾：更新 `项目回顾清单.md`

### 第四步：周复盘（每周日晚）
1. 复制 `周复盘-模板.md`，重命名为 `第X周复盘-YYYY.MM.DD.md`
2. 回顾本周完成情况
3. 总结收获和问题
4. 制定下周计划

## 📁 文件说明

### 目标与计划类
- `2025-Q1-目标.md` - 季度目标，每季度初制定
- `周计划-模板.md` - 周计划模板，每周复制使用
- `周复盘-模板.md` - 周复盘模板，每周复制使用

### 追踪记录类
- `算法刷题记录.md` - 记录每道题的完成情况和复习计划
- `三方库学习清单.md` - Flutter等三方库的学习进度
- `八股文复习计划.md` - 知识盲区记录和复习计划
- `项目回顾清单.md` - 工作项目的技术提炼

## ⏰ 时间管理节奏

### 每日（工作日4h自我提升）
- Flutter学习：1.5h
- 算法刷题：1h（1-2题）
- 八股/性能优化：1h
- 项目回顾：0.5h（每周2-3次）

### 每周
- **周日晚**：周复盘 + 制定下周计划（1h）

### 每月
- **月初**：回顾上月进度，调整本月目标（0.5h）

### 每季度
- **季度初**：制定季度目标（1h）
- **季度末**：季度复盘，调整下季度方向（1h）

## 💡 使用技巧

### 1. 灵活调整
- 工作任务繁重时，可适当减少学习时间
- 利用AI提高工作效率，腾出更多学习时间

### 2. 按需学习
- 八股文不需要系统学习，在项目中发现盲区再补充
- 重点关注性能优化、包体积管理等实用内容

### 3. 及时记录
- 发现可以做成三方库的想法，立即记录到 `项目回顾清单.md`
- 遇到知识盲区，立即记录到 `八股文复习计划.md`

### 4. 复习机制
- 算法题按遗忘曲线复习（3天、7天、15天、30天）
- 八股知识点同样按遗忘曲线复习

---

## 🎯 核心原则

1. **简洁可靠**：模板简单，易于坚持
2. **目标导向**：季度→月度→周度→日度，层层分解
3. **灵活应变**：根据工作情况动态调整
4. **持续改进**：每周复盘，不断优化方法

---

## 📞 常见问题

### Q1：工作任务太多，学习时间不够怎么办？
A：优先保证Flutter学习和算法刷题（至少1题），其他内容可以灵活调整。利用AI提高工作效率。

### Q2：算法题忘了怎么办？
A：正常现象，按遗忘曲线定期复习。重点是理解思路，不是背题。

### Q3：发现新的学习方向怎么办？
A：记录到对应的追踪文件中，在周复盘时评估优先级，决定是否加入下周计划。

### Q4：计划完不成怎么办？
A：周复盘时分析原因，调整下周计划。重要的是持续改进，不是完美执行。
