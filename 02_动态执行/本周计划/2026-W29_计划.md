## 5. 本期处理重点

### 5.1 Baseline Profile 优化

本周只要求能回答这些问题：

- Baseline Profile 优化启动性能的机制是什么：AOT 编译、热点路径、启动路径预编译分别怎么解释？
- Macrobenchmark / Benchmark 在这里负责什么：度量、生成、验证还是防劣化卡口？
- 为什么 Baseline Profile 不能只生成一次：业务路径变化、依赖升级、启动路径变化会导致 profile 过期。
- 如何验证它真的有效：优化前后同环境对比、P50/P90、冷启动/温启动区分、CI 容忍阈值。
- 如何放进长期治理：weekly job 再生成、合入前 Macrobenchmark 卡口、线上启动指标兜底。

### 5.2 启动监控埋点 / 线上监控逻辑

本周只要求能回答这些问题：

- 启动阶段怎么切：进程创建、attach、Application、Activity、首帧 TTID、内容可交互 TTFD。
- 点位怎么埋：客户端轻量 mark，统一 `elapsedRealtime`，避免启动路径上复杂分配。
- 线上怎么采：阶段耗时全量或高比例，慢消息堆栈低比例，按版本、设备、系统、入口分层。
- 怎么发现劣化：P50 环比、低端机 P90 绝对阈值、`TTFD - TTID` gap、灰度版本对照。
- 怎么闭环：告警 -> 阶段定位 -> 慢消息堆栈 / trace 复现 -> git 追溯 -> 修复 -> CI/Checklist 防复发。
