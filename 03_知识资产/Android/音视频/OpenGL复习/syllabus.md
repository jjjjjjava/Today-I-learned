# Android 音视频 OpenGL · 复习大纲

> 这份大纲定义了完成本课题后你将掌握的所有能力。
> 学习深度：标准
> 文档数量因人而异，但掌握内容不打折扣。
> 复习模式：以你已有的 4 篇笔记为准，重在重构知识体系、去代码化、夯实核心原理，不引入无关内容。

## 本课在主链路中的位置

```
解码出 YUV / 解码帧
   ↓
【OpenGL：把帧当纹理 → GPU 处理 → YUV 转 RGB / 滤镜 / 变换】   ← 本课
   ↓
EGL 把渲染结果交给窗口系统
   ↓
SurfaceFlinger 合成 → 上屏
```

## 核心掌握项

完成本课题后，你将能够：

### 模块一 · OpenGL ES 渲染基础与管线
- [x] 能解释为什么视频渲染交给 GPU 而非 CPU（并行度 / 显存带宽），以及 OpenGL ES 在其中扮演的角色
- [x] 能完整复述 GPU 渲染管线六个阶段各自的职责，并用「光栅化插值」解释为什么少量顶点 + 一张纹理就能渲染百万像素
- [x] 能区分屏幕坐标系 / 世界坐标系(NDC) / 纹理坐标系的原点·方向·范围，并说清顶点坐标与纹理坐标如何在每个像素上对应
- [x] 能说清顶点着色器与片元着色器的分工，以及 attribute / uniform / varying 三类变量的区别与数据流向

### 模块二 · 用 OpenGL 渲染视频画面
- [x] 能解释静态图片为何可以每帧 `texImage2D` 上传、而视频帧不能，并说出双 Surface 零拷贝方案的角色分工
- [x] 能描述 SurfaceTexture + OES 外部纹理 + `updateTexImage` 如何让 GPU 直接采样解码帧（为什么是「建立指针指向」而非「拷贝上传」）
- [x] 能说明 FBO 在多级滤镜 / 离屏渲染中的作用（含 FBO 本质=附件挂载点、默认 FBO0 vs 自定义 FBO 差异）

### 模块三 · 矩阵变换与画中画交互
- [x] 能用正交投影矩阵解释视频比例为何会被纠正，并根据 videoRatio 与 screenRatio 判断该缩放宽还是高
- [x] 能说清变换矩阵从 CPU(Kotlin) 传到 GPU(GLSL) 并在顶点着色器中作用的完整链路
- [x] 能解释画中画半透明为什么必须开启混合模式，并说出混合公式的含义
- [x] 能区分平移矩阵(translateM)与缩放矩阵(scaleM)对矩阵的不同改动，并解释平移量为何要乘以投影系数

### 模块四 · EGL 与上屏机制
- [x] 能说清 EGL 的双重职责（跨平台桥接窗口系统 + 替 OpenGL 管理 Context），以及 EGLDisplay / Config / Surface / Context 各代表什么
- [x] 能用 TLS 机制解释 `eglMakeCurrent` 如何让「无参数的 glDrawArrays」画到正确的 Surface，以及为什么 OpenGL API 必须在 GL 线程调用
- [x] 能描述 `eglSwapBuffers` 的作用，并解释双缓冲 / 三缓冲 / VSync 如何解决画面撕裂与渲染阻塞（含 FBO 输出不 swap 的边界）

## 不在本课题范围内

- 通用图形学：光照、3D 几何、模型/视图矩阵、透视投影（本课只聚焦 2D 视频渲染所需的变换）
- 具体滤镜算法本身（高斯模糊、美颜磨皮等的数学实现）
- Camera 采集链路、编码端 `createInputSurface` 的编码输出（属于采集/编码模块，后续单独复习）
- OpenGL ES 3.0+ 新特性（VAO/VBO、UBO、Transform Feedback 等）
