# Android 冷启动机制全流程

> 目标：脱离项目，完整复述从点击图标到首帧上屏。
> 项目应用：[[../00_项目全流程]]

## 五阶段

```text
1. Launcher / ATMS / AMS / Zygote 创建进程
2. ActivityThread.main 建主线程，建立双向 Binder 通道
3. handleBindApplication 创建 Application 与 ContentProvider
4. performLaunchActivity 创建 Activity、PhoneWindow、DecorView
5. ViewRootImpl 接管 View 树，经过 traversal、RenderThread、GPU、SurfaceFlinger 上屏
```

## 阶段入口

1. [[M01_进程创建]]

## 项目中的用途

- 阶段1解释为什么本地口径不从用户点击开始。
- 阶段2解释系统怎样把生命周期工作交给应用主线程。
- 阶段3解释 ContentProvider、Application 初始化与异步化边界。
- 阶段4解释 `setContentView`、inflate、ViewPager、WebView。
- 阶段5解释为什么 `addView` 不等于用户已经看见。

## 全链路评分

1. 阶段顺序正确。
2. 每阶段能说清执行主体。
3. 能说清 Binder、消息、主线程边界。
4. 能说清 PhoneWindow、DecorView、ViewRootImpl 创建时机。
5. 能说清首帧提交与上屏，不把 `onResume` 当终点。
