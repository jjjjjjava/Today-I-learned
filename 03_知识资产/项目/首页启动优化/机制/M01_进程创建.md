# 机制一 · 进程创建

## 主链路

```text
Launcher.startActivity
→ Instrumentation.execStartActivity
→ ATMS 查询 ProcessRecord
→ 无进程，回调 AMS.startProcessLocked
→ Process.start
→ socket 通知 Zygote
→ Zygote fork App 进程
→ 子进程进入 ActivityThread.main
```

## 职责

- ATMS：Activity/Task 调度，判断是否需要新进程。
- AMS：进程与生命周期管理，真正拉起进程。
- Zygote：预加载 ART 与 framework；fork 复用已加载内容。

## 精确点

- Zygote 使用 socket 接收孵化请求。
- fork 返回值：`0` 为子进程，正数为父进程拿到子 pid，负数表示失败。
- 子进程关闭 Zygote socket fd 后进入应用运行入口。

## 项目关联

该阶段主要受系统调度、进程创建和设备状态影响。本项目从 `bindApplication` 开始计算业务可控区间，不等于宣称此前绝对不可优化。
