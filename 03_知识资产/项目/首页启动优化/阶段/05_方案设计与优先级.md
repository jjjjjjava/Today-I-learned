# 阶段五 · 方案设计与优先级

> 回答：怎样让方案对应根因，并按收益与风险排序。
> 事实源：[[../启动优化笔记#5. 方案设计：首屏路径裁剪]]

## 总原则

```text
TTFD 前只做第一屏可见且必须的工作。
其余工作删除、缩短、后置、按需加载或重排。
```

## P0 / P1 / P2

### P0：收益确定，改动聚焦

- ViewPager2 恢复懒加载。
- WebView 移出静态 XML，进入场景时按需创建。

直接对应 `inflate`、`RV OnLayout`、WebView。

### P1：业务相关，回归面更大

- 首页模块首屏裁剪与分批渲染。
- 悬浮组件首帧后或按需创建。

### P2：本项目非主矛盾

- Application 同步初始化瘦身。
- 非首屏 SDK、清理任务等延迟到 Idle 或首帧后。

本项目 `bindApplication` 约 220ms，低于 UI 构建主矛盾。
