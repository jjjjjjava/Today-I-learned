# 阶段九 · 基线与预算回填

> 回答：怎样把一次专项变成持续治理能力。
> 事实源：[[../启动优化笔记#6.8 建立新基线，回填增量治理]]

## 新基线

- 个人手机 Benchmark：约 1.74s。
- 线上 P50：约 1.5s。
- 线上 P90：约 3.1s。
- `startup.stage.home_build` 和关键 Task 使用优化后稳定数据。

## 回填对象

```text
总启动预算
Stage 预算
关键 Task 预算
MR Benchmark
整包自动化
灰度守护
线上长尾监控
```

## 闭环

```text
存量治理降低水位
→ 优化后稳定版本成为新基线
→ 收紧阶段与任务预算
→ 新代码超预算时提前拦截
```

没有预算回填，专项只能产生一次收益；有新基线，存量治理才能转成增量劣化防线。
