# ANR 线上治理｜阅读导航

这套笔记不从 ANR 源码讲起，而是从一次线上问题开始：先判断处理入口，再从一批事件收敛到代表 issue，最后完成单点归因、修复和验证。

```text
日常看板 / 告警机器人
→ 共性归因 / 爆发归因
→ 主要聚类与代表 issue
→ 判断系统正在等待什么
→ 沿线程执行或等待链追到责任方
→ 修复并观察原聚类是否下降
```

## 四篇分别解决什么

| 篇章 | 问题 |
|---|---|
| [[01_线上出现一批ANR_先做什么]] | 一批 ANR 应怎样收敛？ |
| [[02_系统为什么判定这次ANR]] | 系统为什么判定这个样本超时？ |
| [[03_拿到堆栈_怎样追到责任方]] | RUNNABLE、BLOCKED、WAITING、NATIVE 分别怎样继续追？ |
| [[04_找到原因后_怎样完成闭环]] | 怎样修复，并证明原问题已经下降？ |

案例贯穿四篇：“茉莉奶白”用于解释告警和止损，Camera 用于解释主线程 IO，极验用于解释锁链，IJK 用于解释 native 等待。

建议第一次按 `01 → 02 → 03 → 04` 阅读。已有代表 issue 时，可以直接从 03 开始；看不懂 ANR reason，再回到 02。
