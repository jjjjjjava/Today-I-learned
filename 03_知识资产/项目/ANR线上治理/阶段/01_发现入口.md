# 01 · 发现入口

## 两个入口

### 日常线上看板

面对一段时间积累的存量 issue。第一步不是随机挑一条修，而是寻找影响面最大的共同边界。

```text
日常看板 → 共性归因 → 代表 issue → 单点归因
```

### 告警机器人

面对短时间异常上涨。第一步先确认是否真实爆发、影响是否仍在扩大。

```text
机器人告警 → 爆发确认/止损 → 共性切片 → 代表 issue → 单点归因
```

## 入口决定首问

| 入口 | 首先回答 |
|---|---|
| 日常看板 | 这批存量 issue 共同集中在哪里？ |
| 告警机器人 | 是真实爆发吗？为什么是现在？需要先止损吗？ |

入口只决定优先动作，不改变终点：最终都要挑选有代表性且现场有效的 issue，建立主线程因果链。

## 复习检查

1. 为什么日常看板不能从随机单点开始？
2. 告警后为什么不能只看事件量？
3. 两个入口最后在哪里汇合？
