# 鸿蒙 FFmpeg 视频处理 · 项目全流程

## 一句话主线

```text
版本下架整改

→ 解决宿主退出与双向通信

→ 重新上架、开源、回馈上游
```

## 两条业务链

```text
RTSP录像：协议读取 → 解复用 → stream copy → MP4封装
图片水印：解复用 → 解码 → overlay → 硬件编码 → MP4封装
```

## 两轮问题处理

### 第一轮：性能

`150s` 暗示软件编码；指定 `h264_ohosavcodec` 后日志提示 codec 不存在，最终定位构建产物未包含平台适配。更换适配源码、修改 `HPKBUILD` 并重编后降至约 `27s`。

### 第二轮：码率

开源用户反馈 `-b:v` 失效。沿 ArkTS 命令、fftools 解析、Native 参数到 `OH_AVFormat` 排查，定位 `ohosvideoencoder.cpp` 漏写 `OH_MD_KEY_BITRATE`。
