# 06 · RTSP 下载与图片水印落地

## RTSP 录像下载

接口返回设备 RTSP 地址，业务使用主码流。编码与 MP4 兼容时直接复制压缩包：

```text
RTSP协议读取
→ 解复用
→ stream copy
→ MP4封装
```

## 图片水印

水印改变像素，必须完整处理：

```text
输入视频
→ 解码
→ overlay图片合成
→ H.264编码
→ MP4封装
```

## 业务集成

ArkTS 页面负责参数、权限、路径与前置校验；Native 能力负责长任务。进度、成功和失败回调驱动 UI 状态。

无效输入在执行前拦截；RTSP、编解码、写文件等运行错误由 FFmpeg 返回码和失败回调承接。
