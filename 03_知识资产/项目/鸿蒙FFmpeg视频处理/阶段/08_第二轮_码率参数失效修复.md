# 08 · 第二轮：码率参数失效修复

## 触发

开源用户反馈使用 `h264_ohosavcodec` 时 `-b:v` 不生效。

## 排查链

```text
检查-b:v位于输出文件前
→ fftools已解析format_->bit_rate
→ 排除ArkTS命令与fftools解析
→ 下钻ohosvideoencoder.cpp
→ SetCodecFormat漏写OH_MD_KEY_BITRATE
→ 系统编码器使用默认码率
```

## 修复

在 `OH_VideoEncoder_Configure` 前把 `format_->bit_rate` 写入 `OH_AVFormat`，随后重编 `.so`，使用多组目标码率验证，更新 GitHub/OHPM，并向 OpenHarmony 上游提交 Issue。

## 验证边界

`-b:v` 控制视频轨码率；文件总码率还含音频与封装开销。应使用 `ffprobe` 查看视频轨，不能只看文件信息页总码率。
