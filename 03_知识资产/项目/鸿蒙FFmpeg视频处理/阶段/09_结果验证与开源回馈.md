# 09 · 结果验证与开源回馈

## 业务结果

- 录像下载与图片水印完成落地；
- 应用完成整改并重新上架；
- ArkTS 业务层获得可复用 FFmpeg Native 能力。

## 技术验证

- 功能：RTSP 下载、图片水印、进度、成功、失败；
- 稳定性：连续多任务串行执行，状态不污染；
- 性能：公司阶段 `150s → 27s`；
- 码率：视频轨随目标值变化，输出可播放。

## 开源闭环

能力发布至 GitHub 与 OHPM。社区 Issue 触发第二轮底层定位，修复后重新发布并向 OpenHarmony FFmpeg 上游反馈。

## 口径边界

后续开源 README 的 `15.68s` 属于不同版本或环境，不能与公司阶段 `150s → 27s` 混作同一实验。
