## 原理链

```text
容器解封装
→ 取出压缩音视频包与时间戳
→ 解码得到可处理画面
→ 修改像素
→ 重新编码
→ 封装为MP4
```

不改变画面时，不应无条件解码：

```text
RTSP → 解复用 → stream copy → MP4封装
```

图片水印会改变每帧像素：

```text
输入视频 → 解码 → overlay合成 → 编码 → MP4封装
```

## 为什么选 FFmpeg

组合方案需要分别处理 RTSP、解复用、图像合成、编码和封装，还要维护时间戳、异常与资源生命周期。FFmpeg 的 `libavformat/libavcodec/libavfilter` 加 fftools 命令编排能统一承载两条业务链，适合紧急整改及后续复用。
