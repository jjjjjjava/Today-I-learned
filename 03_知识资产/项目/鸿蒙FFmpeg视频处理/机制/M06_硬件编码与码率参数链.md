# M06 · 硬件编码与码率参数链

## codec 可用链

```text
命令指定h264_ohosavcodec
→ fftools查找codec
→ 当前.so必须注册对应适配
→ Native封装调用OH_VideoEncoder
```

codec 不存在通常表示构建产物缺少注册或适配，不是继续调整 `-c:v` 位置就能解决。

## 码率链

```text
-b:v 300k
→ fftools解析
→ format_->bit_rate
→ ohosvideoencoder.cpp
→ OH_AVFormat_SetLongValue
→ OH_MD_KEY_BITRATE
→ OH_VideoEncoder_Configure
```

漏掉最后的 `OH_AVFormat` 写入，系统编码器只能使用默认码率。
