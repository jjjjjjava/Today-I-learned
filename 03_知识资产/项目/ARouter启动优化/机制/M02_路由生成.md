# 机制二 · 路由生成

## 输入

业务类通过注解声明：

```kotlin
@Route(path = "/user/login")
class UserLoginActivity : Activity()
```

## APT链路

```text
@Route
→ RouteProcessor
→ RoundEnvironment取得标注Element
→ 解析注解与类型
→ 构造RouteMeta
→ 按group整理
→ JavaPoet生成Java源码
→ 编译为Class
```

Element是编译期结构描述，不是运行时Class实例。

## 生成物

- `ARouter$$Group$$user`：写入`path → RouteMeta`。
- `ARouter$$Root$$app`：写入`group → Group Class`。
- `ARouter$$Providers$$app`：写入Provider映射。
- Interceptor处理链生成对应索引Class。

生成完成只代表路由表Class存在于构建产物；初始化期仍需发现这些Class并调用`loadInto()`。

## 职责边界

- RouteProcessor：扫描、解析、组织元数据。
- JavaPoet：生成Java源码。
- Gradle插件：处理已编译Class并写入注册逻辑。
- D8：把最终Class转为Dex。
