# ARouter 启动优化｜阅读导航

这套笔记围绕一次构建升级引发的启动增量劣化展开。重点不是从头学习 ARouter，而是还原线上发现、运行时归因、编译期修复和防复发过程。

```text
灰度 LOW 档 P90 异常上涨
→ 暂停放量并下钻 Stage / Task
→ Profiler 定位 ARouter 的 Dex 扫描
→ 源码解释为什么会回退慢路径
→ 恢复编译期注册
→ 解决 variant 与 Java 21 兼容问题
→ 用产物、运行、性能和功能完成验证
```
